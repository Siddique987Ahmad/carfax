# setup/05 — CI on pull requests

Status: in progress: workflow done (Nov 27, 2026); branch protection and the first real run need GitHub settings · Phase: pre-pilot · Depends on: setup/01, setup/03

## Goal
Every pull request is checked automatically, so broken types, failing tests or a forgotten migration can't reach `main`.

## Decisions
- **GitHub Actions,** as in the tech doc.
- **Only check what changed,** using Turborepo's filter against `main`, to keep runs fast.
- **Real Postgres and Redis in CI** (service containers), so API and worker tests use the same database as production.
- **Migration check:** CI runs `drizzle-kit generate` and fails if it produces a new file. That means someone changed the schema without committing the migration.
- **`main` is protected:** checks must pass before merging. **One review is required only once there are two developers**; with one, nobody could approve their own pull request.
- **Branch protection on a private repo needs a paid GitHub plan** (Pro for a personal account, or Team for an organisation). GitHub Free enforces it only on public repos, and this repo must stay private (it holds the business docs).
- **Pull requests check only affected packages** (`turbo --affected`, compared with `main`); pushes to `main` check everything. Root config changes (lockfile, `turbo.json`, base configs) make Turborepo check everything anyway.
- **Pinned versions:** `actions/checkout@v7`, `actions/setup-node@v7` (Node from `.nvmrc`, pnpm cache), `pnpm/action-setup@v6` (pnpm from `packageManager`), and the same Postgres and Redis images as `infra/docker-compose.yml`.
- **The migration check is already in the workflow** and switches on by itself when `packages/db/drizzle.config.ts` exists. db/01 must keep that path and make `pnpm --filter @carfax/db exec drizzle-kit generate` work.

## Scope
**In:**
- `.github/workflows/ci.yml`: install (with pnpm cache), lint, typecheck, test, migration check, i18n check (setup/04)
- Postgres 16 and Redis service containers
- Branch protection on `main`

**Out (later items):**
